# Bundled fonts

Copied from `~/projects/home/jarvis/frontend/public/fonts/`, the canonical set for the
instrument house style. Self-hosted rather than fetched from a CDN so no visitor
IP is handed to a third party. Only the Latin subsets are here (~65 KB total).

Manjari is deliberately left out: the site has no Malayalam text. If some is
added, copy `Manjari-*.woff2` from Jarvis and declare them with the
`unicode-range` used there.

All are licensed under the **SIL Open Font License 1.1**, which permits
redistribution alongside this project.
